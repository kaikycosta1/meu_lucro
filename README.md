# 💰 Meu Lucro

Aplicativo de controle financeiro desenvolvido para **microempreendedores**, com o objetivo de facilitar o gerenciamento de vendas, produtos, estoque e resultados do negócio.

Projeto desenvolvido para a **FETIN - Inatel**.

---

## 📱 Sobre o projeto

O **Meu Lucro** foi desenvolvido pensando na rotina de pequenos empreendedores que precisam de uma maneira simples e prática de acompanhar o seu negócio.

A aplicação reúne ferramentas para auxiliar no controle das principais informações financeiras e operacionais, permitindo uma visão mais clara dos resultados.

---

## 🚀 Funcionalidades

- 📊 Dashboard com informações do negócio
- 💰 Controle de vendas
- 📦 Gerenciamento de produtos
- 🏪 Controle de estoque
- 📉 Registro de perdas
- 📈 Relatórios
- 🧾 Controle de itens e ingredientes
- 🤖 Recursos de inteligência artificial
- 🔐 Sistema de autenticação

---

## 🛠️ Tecnologias utilizadas

- **Flutter**
- **Dart**
- **Firebase**
- **Cloud Functions**

---

## 🎯 Objetivo

Desenvolver uma solução acessível e intuitiva para ajudar microempreendedores a organizar melhor suas operações e acompanhar seus resultados financeiros.
